# ReGravity Defied

### Open-source порт класичної J2ME-гри про мотоциклетний тріал **Gravity Defied**

## ✨ Можливості

| | |
|---|---|
| 🏁 **Автентична фізика** | Динаміка мотоцикла перенесена з оригіналу та 3 ліги двигунів (**100cc · 175cc · 220cc**). |
| 🧍 **Рухомий гонщик** | Складений зі з'єднаних частин спрайт (ноги, торс, рука, шолом), який нахиляється разом із мотоциклом. |
| 🎨 **Кастомізація** | Перефарбовуйте шолом, костюм гонщика й мотоцикл зі спільної палітри з живим попереднім переглядом; вибір зберігається разом із прогресом. |
| 🔓 **Прогресія** | Першу трасу відкрито одразу; проходження траси відкриває наступну, а завершення ліги відкриває наступну лігу. |
| ⏱️ **Найкращі часи й курсор** | Таблиця рекордів для кожної траси та запам'ятовування останньої відкритої траси в кожній лізі збережене на SD-карті. |
| ⚡ **Швидка навігація** | Утримуйте Вгору/Вниз, щоб автоматично прокручувати довгі списки ліг і рівнів. |
| 🔊 **Звук** | Звуковий ефект аварії через п'єзодинамік та I2S. |
| ⚙️ **Налаштування** | Вибір кнопок нахилу, перемикач звуку, скидання прогресу (з підтвердженням) і екран «Про гру». |

## 🎮 Керування

| Кнопка | Дія |
|:---|:---|
| **A** | Газ · підтвердити |
| **B** | Гальмо · назад |
| **← / →** | Нахил *(D-pad tilt mode)* |
| **C / D** | Нахил *(shoulder tilt mode)* |
| **↑ / ↓** | Навігація меню · **утримуйте для швидшої прокрутки** |
| **START** | Вибрати · старт |
| **SELECT** | У грі: меню траси · у меню ліги: налаштування |
